# SEMITS Quest — Handheld Learning Game

Original browser-based Year 2 learning game with maths racing, English block-building, science exploration and writing activities. Inspired by broad arcade and handheld gameplay styles, with original branding.

## Play
After GitHub Pages is enabled for this repository, open `https://parthanetworkconnect-byte.github.io/glen/semits-quest/`.

## GitHub Pages setup
1. Repository **Settings → Pages**.
2. Under **Build and deployment**, set Source **Deploy from a branch**.
3. Select `main` and `/(root)`, then Save.
4. The site will be served at the URL above after GitHub completes deployment.

## Important limitations
- This is a **browser game**, not a Nintendo Switch 2 game or emulator.
- No real Nintendo, Roblox, Mario or Fortnite assets are included.
- Player progress is stored **only in local browser storage** and is not synced between devices.
- Parent PIN protects against casual access inside the app but is **not secure authentication**. Do not store sensitive child information.
- Website hosting is public; app code is publicly visible.
- Gameplay has not been exhaustively browser-tested on every device.
